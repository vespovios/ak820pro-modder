Local macOS Apple Silicon compatibility build
Base: v0.7.0-beta, commit 382d59ced1c17abb27e0c1c247049cb473e69b66

Added support for the AK820 feature-report protocol on USB usage page
0xFF13, including product ID 0x800A. The original output-report protocol
remains available for devices without that feature-report endpoint.

Available on this revision:
- 20 global lighting effects, colour, brightness, speed, direction, rainbow.
- ANSI per-key RGB: Lighting > custom, click to paint, Fill/Clear, brightness,
  explicit Apply and local saved profile. Hardware-verified WASD and E mapping.
- Multiple named per-key profiles with brightness, save/update/delete, and
  Use profile to load and apply. Existing colours become "Current colours".
- Global colour-profile cycling shortcut (Control+Option+Command+P by default),
  configurable/disableable while the app is open. JSON file import/export
  supports sharing and prepared ANSI profiles; see docs/examples/gaming-colours.json.
- Complete setups: lighting, sleep, Mac remaps/macros and embedded TFT image/GIF,
  save/update/delete, import/export, and a separate Control+Option+Command+S
  cycling shortcut. See docs/SETUP-PROFILES.md for capture and apply semantics.
- App-based complete setup rules: foreground macOS app detection, persisted app-to-setup
  assignments, fallback/keep-current, debounce, pause, and no repeat screen upload
  when the same setup remains unchanged. Setup profiles > Switch setups by app.
- Display clock sync from the Mac's local time.
- Standby: never, 1, 5 or 30 minutes.
- Preset lighting and host-side automation library components.
- Device-scoped key remapping on this Mac, restored while the app is open.
- Local macro recording, saving, key binding and playback (Accessibility required).
- TFT PNG/JPEG/WebP images and GIF animations, centre-cropped to 128x128.
  Maximum 10 MB source, 30 frames. Upload and per-block acknowledgements.

Unavailable: firmware/battery/current-settings telemetry, onboard keymap
and macro uploads, hardware Fn/knob remapping and audio-reactive
lighting. Mac-side controls replace onboard remapping/macros for this unit.
TFT uses the FF68 4096-byte data endpoint with AKS075 framing; the user
confirmed the four-colour test image appeared on the physical screen.

See docs/COMPATIBILITY.md for protocol details and validation evidence.

See docs/MAC-SIDE-CONTROLS.md for Mac-side controls and permissions.
See docs/PER-KEY-RGB.md for the ANSI colour-bank protocol.

Build locally (Apple Silicon Node and Rust must be on PATH):
pnpm tauri:build --bundles app,dmg --config '{"bundle":{"macOS":{"signingIdentity":"-"}}}' -- --locked

Output: target/release/bundle/macos/AK820 Pro Modder.app
Installer: target/release/bundle/dmg/AK820 Pro Modder_0.7.0-beta_aarch64.dmg
